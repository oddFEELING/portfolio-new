# Blog Phase 3 Implementation Plan

> **For agentic workers:** Presentation tool + preview mode + visual editing overlays.

**Goal:** Editors can open the portfolio site inside Sanity Presentation, see draft content live, and click-to-edit via overlays.

**Architecture:** Cookie-based preview mode (`@sanity/preview-url-secret`) enables `perspective: drafts` + stega only while previewing. Split loaders already in place; blog loaders pass preview options. Studio gets `presentationTool` with location resolvers.

**Spec:** `docs/superpowers/specs/2026-07-16-blog-design.md` Phase 3

## Scope

- Preview enable/disable API routes
- Preview session cookie + `getPreviewData`
- Blog loaders pass perspective/stega; preview queries include drafts
- `SanityVisualEditing` + `useLiveMode` when preview
- Studio Presentation tool + document locations
- `stegaClean` for meta/slug logic
- Require `SANITY_API_READ_TOKEN` (Viewer) for draft reads

## Out

- Shared preview access UX polish beyond disable link
- Presentation queries for individual PTE blocks
- Production Studio deploy automation
