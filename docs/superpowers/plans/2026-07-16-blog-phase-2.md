### Task 1: GROQ queries for tags + related candidates

**Files:**
- Modify: `app/sanity/queries.ts`

- [ ] **Step 1: Add queries**

Append:

```ts
/** All tags that have at least one published post. */
export const TAGS_QUERY = defineQuery(`
  *[_type == "tag" && count(*[_type == "post" && defined(publishedAt) && !(_id in path("drafts.**")) && references(^._id)]) > 0]
  | order(title asc) {
    _id,
    title,
    "slug": slug.current,
    description
  }
`);

/** One tag by slug. */
export const TAG_QUERY = defineQuery(`
  *[_type == "tag" && slug.current == $slug][0]{
    _id,
    title,
    "slug": slug.current,
    description
  }
`);

/** Published posts that reference a tag slug. */
export const TAG_POSTS_QUERY = defineQuery(`
  *[_type == "post" && defined(slug.current) && defined(publishedAt) && !(_id in path("drafts.**"))
    && $tagSlug in tags[]->slug.current]
  | order(publishedAt desc) {
    _id,
    title,
    "slug": slug.current,
    publishedAt,
    excerpt,
    coverImage,
    tags[]->{
      _id,
      title,
      "slug": slug.current
    }
  }
`);

/** Tag slugs for sitemap. */
export const TAG_SLUGS_QUERY = defineQuery(`
  *[_type == "tag" && defined(slug.current)
    && count(*[_type == "post" && defined(publishedAt) && !(_id in path("drafts.**")) && references(^._id)]) > 0]{
    "slug": slug.current
  }
`);

/** Candidate posts for related fallback (exclude current). */
export const RELATED_CANDIDATES_QUERY = defineQuery(`
  *[_type == "post" && defined(slug.current) && defined(publishedAt) && !(_id in path("drafts.**"))
    && _id != $postId]
  | order(publishedAt desc)[0...12] {
    _id,
    title,
    "slug": slug.current,
    publishedAt,
    excerpt,
    "tagSlugs": tags[]->slug.current
  }
`);
```

Also tighten `POST_QUERY` relatedPosts projection with published filter:

```
relatedPosts[]->[defined(publishedAt) && !(_id in path("drafts.**"))]{
```

### Task 3: Index filter `?tag=`

**Files:**
- Modify: `app/routes/blog.tsx`

- [ ] **Step 1: Loader**

```ts
export async function loader({ request }: Route.LoaderArgs) {
  const url = new URL(request.url);
  const tag = url.searchParams.get("tag");

  const [postsResult, tagsResult] = await Promise.all([
    tag
      ? loadQuery(TAG_POSTS_QUERY, { tagSlug: tag })
      : loadQuery(POSTS_QUERY, {}),
    loadQuery(TAGS_QUERY, {}),
  ]);

  return {
    postsInitial: postsResult,
    tagsInitial: tagsResult,
    activeTag: tag,
    postsQuery: tag ? TAG_POSTS_QUERY : POSTS_QUERY,
    postsParams: tag ? { tagSlug: tag } : {},
  };
}
```

Use `useQuery` for posts (and optionally tags). Show a chip row above the list with `linkTo="filter"`. Count reflects filtered list. Empty filtered state: “No posts with this tag.” + link clear filter.

Unknown tag slug with zero posts: still show empty filtered state (do not 404 the index).

- [ ] **Step 2: Smoke**

`/blog?tag=architecture` shows seed post; `/blog?tag=nope` empty filtered.

### Task 5: Related posts on article page

**Files:**
- Create: `app/lib/blog/related.ts`
- Create: `app/components/blog/related-posts.tsx`
- Modify: `app/routes/blog.$slug.tsx`

- [ ] **Step 1: Resolver**

```ts
export type RelatedPost = {
  _id: string;
  title: string;
  slug: string;
  publishedAt?: string | null;
  excerpt?: string | null;
};

export function resolveRelatedPosts(options: {
  manual: RelatedPost[] | null | undefined;
  candidates: Array<RelatedPost & { tagSlugs?: string[] | null }>;
  currentTagSlugs: string[];
  limit?: number;
}): RelatedPost[]
```

Logic:
1. Take up to `limit` (3) from `manual` (filter nulls / missing slug)
2. If fewer than limit, fill from `candidates` sharing any `currentTagSlugs`, newest first, exclude already picked
3. If still fewer, fill from remaining `candidates` by recency

- [ ] **Step 2: Loader**

After loading post, if post exists:
- `loadQuery(RELATED_CANDIDATES_QUERY, { postId: post._id })`
- `related = resolveRelatedPosts({ manual: post.relatedPosts, candidates, currentTagSlugs: post.tags.map(t => t.slug).filter(Boolean) })`
- Return `related` in loader data (plain data, not useQuery — fine for Phase 2)

- [ ] **Step 3: UI**

`RelatedPosts` — bordered footer list under body: heading “Related”, links to `/blog/{slug}`, date + title (+ optional excerpt). Hide section if empty.

Tag chips on the article page should use `TagChips` with `linkTo="archive"`.
